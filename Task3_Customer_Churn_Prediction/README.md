# Bank Customer Churn Prediction

# Overview
This project predicts whether a bank customer is likely to leave (churn) or continue using the bank's services based on customer demographics and banking-related information. A Random Forest Classifier is used to build the prediction model.

#Dataset
Bank Customer Churn Prediction

Source:
https://www.kaggle.com/datasets/shantanudhakadd/bank-customer-churn-prediction

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

#Machine Learning Model
- Random Forest Classifier

#Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore and understand the data.
4. Check for missing values.
5. Perform Exploratory Data Analysis (EDA).
6. Encode categorical features.
7. Split the dataset into training and testing sets.
8. Train the Random Forest Classifier.
9. Evaluate the model using Accuracy, Classification Report, and Confusion Matrix.
10. Save the trained model ('customer_churn_model.pkl').
